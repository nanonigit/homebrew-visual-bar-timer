# Homebrew Tap for VisualBarTimer

Official Homebrew tap for [VisualBarTimer](https://github.com/nanonigit/VisualBarTimer).

## Installation

```bash
brew install --cask nanonigit/visual-bar-timer/visual-bar-timer
```

or

```bash
brew tap nanonigit/visual-bar-timer
brew install --cask visual-bar-timer
```
